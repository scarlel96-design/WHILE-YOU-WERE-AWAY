# 0.3 도시 미술 · 일곱 번째 출발

## 이번 구현

도시를 기능 확인용 회색 상자에서 벗어나게 하는 첫 미술 개선입니다. 중심 구역 80×80은 유지하며, 주변부를 포함한 배치 범위는 136×136으로 늘렸습니다. 완성형 대도시나 최종 아트라는 의미는 아닙니다.

- 벽돌 주거동, 흰 진료소, 산화 구리 작업장, 석재 방송동으로 재질을 나눴습니다.
- 발코니, 난간, 배관, 입구 차양, 균열, 무너진 벽과 잔해를 추가했습니다.
- 작업장은 지붕 채광창과 높은 굴뚝을 갖습니다. 다른 건물에도 서로 다른 옥상 설비를 배치했습니다.
- 길 중앙에는 버려진 전차를 두고, 길 끝에는 지지 기둥이 있는 시계탑을 배치했습니다.
- 도시 밖에는 수로, 높낮이가 있는 둑, 고사목, 파손된 옥상의 외곽 건물 8동을 추가했습니다. 이들은 배경용이며 별도 탐험 콘텐츠는 아직 없습니다.
- 지상층에는 대기 의자와 낮은 조명, 접수대 등 기록과 연결되는 소품을 넣었습니다. 상층부의 계단·방별 생활 흔적은 후속 작업입니다.

## 공포 장면: 일곱 번째 출발

접수 장부에는 의자 24개와 이름 31개가 남아 있습니다. 북쪽 출발로에는 사슬에 걸린 빈 의자 7개가 있습니다. 문을 닫아야 했던 방송실 기록과 같은 사건입니다.

장부를 읽고 북쪽 출발로에 접근하면, 잠시 아무것도 없던 의자 아래에 창백하게 접힌 형체 일곱이 나타납니다. 형체들은 일정 시간 정지했다가 짧은 충격음과 함께 동시에 내려와 멈추고, 잠시 뒤 사라집니다. 카메라를 강제로 돌리거나 화면 전체를 번쩍이지 않습니다. 형체가 플레이어를 공격하거나 서버에 영구 몬스터로 남지는 않습니다.

- 조건: 새 미술판 도시, 접수 장부 읽음, 출발로 반경 14블록, 독서/이동 유예 종료, 생존·모험 상태, 체력 4칸 이상, 평화로움 아님, 조우 설정 켜짐.
- 단서는 반복 독서로 중복 누적되지 않습니다. 장면은 플레이어별 한 번만 시작하며 그 상태는 저장됩니다.
- 메뉴·책 열기, 사망, 차원 이동, 현장 이탈은 현재 장면과 임시 형체를 정리합니다. 중간에 닫아도 본 것으로 처리합니다.
- 기존 귀로꾼 모델과 설치된 Minecraft의 스켈레톤 재질 참조를 재사용했습니다. 신규 몬스터 7종을 만든 것은 아닙니다.
- 기존 원본 합성 효과음의 호출 시점을 조정한 장면입니다. 이번 버전에서 새 음악이나 음원을 만들지는 않았습니다.

## 기존 월드와 새 월드

이미 생성된 0.2 도시에는 새 건물 배치를 덮어쓰지 않습니다. 기존 건축물, 플레이어가 놓은 블록, 생성 진행 순서를 그대로 보존합니다. **0.3의 새 도시 배치를 보려면 새 테스트 월드를 생성하세요.** 0.2에서 아직 도시 배치 데이터를 만들지 않은 월드도 새 배치를 사용합니다.

도시 생성 계획은 `CityLayout` 버전 1과 `CityArtLayout` 버전 2로 분리했습니다. 이야기 저장 형식은 3으로 올라가며, 추가 필드 `cityShockTriggered`의 기본값은 false입니다.

복구 스크립트는 지정한 JAR 복사본을 0.2 바이트로 되돌리는 시험용 도구입니다. 월드나 원본 소스를 되돌리지 않으며, 도시 저장 데이터를 구버전으로 다운그레이드한 검증과 다릅니다.

## 검증 구분

자동 검사: 배치 셀 중복·범위·주요 기록까지의 지상 연결성, 구 배치 보존, 저장 필드, 도시 이동, 기록 읽기, 귀환, 재진입, 7형체 장면과 정리, 프로세스 재시작 후 유지.

자동 클라이언트는 진행 상태를 준비한 전용 월드에서 검사합니다. 자연 생존 전 과정을 사람이 플레이한 결과, 동시 접속 2인 검증, 최종 사운드 청감 평가와 구분합니다. 모든 테스트 클라이언트는 시작 전에 전체 소리·각 분류·내레이터를 끕니다.

후속 아트 작업: 방마다 다른 실내 동선과 생활 흔적, 원본 괴물 텍스처, 거리별 비대칭 구조, 밀도 높은 외곽 지형, 추가 서사 장소. 다중 엔딩과 방대한 전체 캠페인은 아직 개발 중입니다.
