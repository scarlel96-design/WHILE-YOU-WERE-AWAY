# WHILE YOU WERE AWAY — 장편 콘텐츠 지도 및 향후 구현 우선순위

상태: **기획/누락 방지용 백로그**. 2026-11-02 스냅샷. 이것은 현재 작업지시서가 아니며 V2-03 범위를 소급 변경하지 않는다.
연속성 기준: [PROJECT_CONTINUITY.md](PROJECT_CONTINUITY.md). 구현/검증 상태는 항상 GitHub 최신 evidence·코드에서 재확인한다.

## 1. 전체 캠페인 범위

- Prologue: 플레이어의 1인칭 기억 파편 → 자연스러운 오버월드 생존.
- Act I: 작고 서로 관련 없어 보이는 오버월드 흔적·첫 NPC·첫 위협.
- Act II: 철도·신호·반복 장소·시간의 연결성 탐색.
- Act III: 저녁골의 현재 생활과 사라진 주민/과거 기록 조각의 모순.
- Act IV: 연속기의 설명을 검증하고 그 설명의 한계를 발견.
- Act V: 서로 충돌하는 마지막 하루·도윤의 선택·여울·미루의 기록 재해석.
- Act VI: 존재하지 않았던 어제·플레이어 과거·독립적인 Observer 흔적 심화.
- Act VII: 준비한 해법 실행·인물의 현재 자율성 보존·다섯 결말과 이후 세계 변화.

이 요약은 [DESIGN_V05.md](DESIGN_V05.md)의 스토리를 대체하지 않는다. 장별 내용은 확정 세부가 아닌 **계획 구분**이다.

## 3. 단계별 전략

**현재 작업: V2-03 (변경 금지)**  
기존 지시서와 진행 중인 구현·검증을 그대로 마무리한다. 이 문서로 새 요구를 추가해 V2-03을 회수하거나 FAIL 처리하지 않는다. [V2_03_CONTENT_STATUS.md](V2_03_CONTENT_STATUS.md)에서 실제 결과를 확인한다.

**다음 작업부터: 콘텐츠 중심 연속 구현**
- 1순위: 실제 탐험 동선과 고품질 장소를 연결한다. 소규모 구조물·지형 탐색·공정한 발견·장기 복선의 자리까지 설계한다.
- 병행 핵심: 귀로꾼 등 실재하는 Threat의 외형·행동·사운드가 실제 공포를 만들게 한다. 고유 위험 신호는 일관되게 유지한다.
- 대표 장면: 원거리 공간 이상과, 장면 이후 흔적이 남는 대규모 세트피스를 **서로 다른 작업 단위**로 취급한다. 게임이 아닌 문서/효과음 리스트만으로 완료하지 않는다.
- 생활/미스터리: 여울·도윤·미루의 자율적 활동, 오버월드↔저녁골 탐사, 퍼즐·조사·장비가 함께 누적되도록 한다.
- 후반 본편: 플레이어 과거의 회수, 교차 기록, 기록관/연속기의 실제 원리, 다섯 엔딩·후일담. 모든 비밀의 해답을 미리 강제 확정하지 않는다.
- 마지막 통합: 임시 자산을 교체하는 전체 리소스팩/환경/음향/시네마틱 폴리싱, 사용자 경험 결과에 따른 조정, 릴리스 평가.

## 4. 50–60% 통합 플레이테스트의 판정

- **분모 확정 전 완성률 = UNKNOWN**.
- 기능별 구현/실제 접근 가능한 플레이 경로/콘텐츠 분량을 세분화하고, 전체 분량을 먼저 고정한다.
- 자산 수·클래스 수·GameTest 수·한 WO 완료율로 대체하지 않는다.
- 각 항목에 PLANNED / IN PROGRESS / IMPLEMENTED / AUTOMATED VERIFIED / HUMAN VERIFIED / NOT TESTED 및 근거 경로를 기록한다.
- 전체 구현 콘텐츠가 약 50–60%가 되면 사용자가 일반 Minecraft를 직접 플레이한다. 배포 가능한 JAR, 의존성, 새 월드/기존 월드 안내, 평가용 지침, 알려진 제한 사항을 제공한다.
- 목표 이전에도 컴파일·저장 안정성·Actor·checkpoint·transaction·월드 보호·필요한 자동 통합 검사는 지속한다.
- 인간의 공포/청각/미적 품질은 자동 테스트로 PASS 처리하지 않는다.

## 5. 설계 작업의 품질 게이트

- **장소:** 원래 용도·동선·실제 사용 가능성·기억성·반복 방문 의미·장기 복선의 ID.
- **괴물:** 독특한 실루엣·애니메이션·음향·학습 가능한 규칙·실제 위기와 회복·성능.
- **환경 장면:** 장면 목표·사전 전조·거리·플레이어가 할 수 있는 행동·일관된 위협 신호·종료 후 흔적·충돌 및 저장 안전성.
- **미스터리:** 관찰 사실·기대 가설·반례·재확인·장면 회수·중요한 비밀의 독립성.
- **NPC:** 일상과 선택권·플레이어 부재 시 일관성·기존 actor 동일성·감정의 원인.
- **엔딩:** 준비와 선택의 인과·플레이어 숙련 존중·후일담·월드 지속성.

위 게이트의 "품질"은 구현 여부와 별도로 인간 평가에서 확인한다. 프로그램이 실행된 사실만으로 공포·감동·미감을 확인했다고 주장하지 않는다.
