# 《네가 없는 동안》 설계 개선안 v0.4 — 상위 설계 계약

상태: **설계 채택 / 콘텐츠 구현 보류**. 설계 문서 버전 v0.4는 모드 릴리스 버전이 아니다. 현재 모드는 0.3.1-dev.1, 전체 안정화 PARTIAL, save format 4, optional actorSchema 1, city art revision 2를 유지한다.

이 문서는 사용자가 제공한 설계 개선안 25개 항목을 개발 기준으로 정리한 것이다. 기존 33–81 설계 중 아래와 충돌하는 세계관 해석은 이 문서가 우선한다. 저장 안정화, 창작물 보호, 접근성, 실제 검증, 최종 아트 보류 원칙은 그대로 유지한다. 참고 작품의 최근 버전·개별 장면·연구 수치·인용에 관한 원문 주장은 이번에 외부 검증하지 않았으며, 검증된 연구 결과로 재인용하지 않는다.

## 1. 작품 명제

**정체성이란 과거와 얼마나 똑같은가가 아니라, 현재에서 계속 달라질 수 있는 권리다.**

연속기의 대립 명제는 “빈자리는 오류다. 차이는 손상이다.”이다. 플레이어는 악당 제거나 완벽한 과거 복원이 아니라, 빈자리와 변화가 정상으로 인정되는 세계를 준비한다.

## 2. Continuity Graph

연속기가 보존한 핵심은 사람의 복사본이 아니라 사람·장소·역할 사이의 관계다. 귀가할 집, 불을 켤 창문, 일할 자리, 기다리는 상대, 철도의 목적지, 병상, 식탁 자리가 관계의 단위다.

핵심 회수: **“연속기는 사람을 기억한 것이 아니라, 빈자리를 기억하고 있었다.”**

집·길·철도·작업실을 만드는 Minecraft 행동은 새로운 관계를 실제로 구성한다. 미래 구현에서 관계를 단일 호감도나 기존 자리를 채웠다는 boolean으로 축소하지 않는다.

## 3. 공포 존재: 주어를 잃은 동사

- 귀로꾼 / Wayfarer: 목적지는 사라졌지만 돌아가는 행동이 남았다.
- 검표관: 누가 이곳에 있어도 되는지 확인하는 규칙이 남았다.
- 수선·바느질 계열: 사람·건물·기억을 가리지 않고 원래 상태로 고치는 기능이 남았다.
- 마지막 승객: 목적지 없는 대피 행동이 남았다.
- 일곱 형체: 일곱 희생자의 확정된 신원이 아니라, 항상 사람이 있어야 한다고 기록된 일곱 자리다. 시대별 이름은 달라도 칸 수는 같다. 후반에 플레이어의 행동·장비 특징을 일부 반영하는 후보 연출은 빈자리에 편입될 위험을 드러낸다.

모든 괴물을 이 원리 하나로 완전히 해부하지 않는다. 초기 단서가 곧바로 정답을 선언하지 않게 한다.

## 4. 존재하지 않았던 마지막 하루

저녁골의 반복되는 하루는 여러 날짜의 파편을 조합한 합성본이다. 병원·철도·학교의 날짜, 날씨, 계절, 생활 흔적의 모순은 사전에 확인 가능해야 한다.

핵심 회수: **“우리가 돌아가려고 했던 어제는, 한 번도 존재한 적이 없었다.”**

배드엔딩 「완벽한 복원」은 실제 누구도 살아본 적 없는 완벽한 과거를 정상으로 강제한다. 기존 경험을 꿈이나 무의미한 가짜로 취소하는 반전으로 쓰지 않는다.

## 5. 기록관

기록관은 단일한 미친 AI가 아니라, 인간들이 만든 철도 대피·환자 우선순위·주민 명부·봉쇄·배급·복원·시설 관리 비상규칙이 겹쳐 관리 인격처럼 작동한 결과다.

**“이 시스템은 인간이 시킨 일을 너무 정확하게 계속하고 있다.”** 당시 사람들의 절박함과 책임을 함께 남긴다.

## 6. 비점프스케어 공포 계층

주요 심리 공포 장면은 몬스터, 큰 충격음, 강제 카메라 없이도 성립하도록 설계한다. 이것은 주관적 공포 효과까지 자동 테스트로 증명했다는 뜻이 아니다. 기능 검사와 사람의 플레이 평가를 구분한다.

## 7. 심리 공포 장면 후보

| 장면 | 관찰과 회수 | 지속되는 사실 |
|---|---|---|
| 귀환망이 집을 찾았다 | 복구한 철도 안내도에 재난 이후 지은 플레이어 집이 종착점으로 등록됨 | 세계가 현재 생활권을 인식함; 집을 파괴하지 않음 |
| 주어 없는 작업장 | 사람 없이 교대·도구 준비·작업·휴식이 반복되고, 빈 작업 위치에 선 플레이어 때문에 전체 사이클이 완성됨 | 자리는 특정 사람보다 역할의 충족을 요구함 |
| 현재가 과거에 있었다 | 여울과 만든 독특한 블록 배치가 나중에 과거 재구성 자료에 나타남 | 연속기가 현재를 근거로 과거를 수정함; 실제 역사 자체의 시간여행으로 단정하지 않음 |
| 오늘의 여울은 너무 멀쩡하다 | 여울은 친절하고 정상적으로 보이지만 함께 만든 작업실·갈등·농담을 기억하지 못함 | 현재 경험이 교정 대상으로 취급됐음을 드러냄 |

모두 디자인 후보다. 이번 안정화 테스트에 끼워 넣지 않는다.

## 8. Signature Setpiece Standard

복선 → 불가능한 규모 → 실제 움직임 → 통합 음향 → 물리적 상호작용 → 월드 변화 → 잔해 또는 후속 상태 → 재방문.

참고작의 고유 디자인·코드·사운드·장면을 복제하지 않는다. 효과를 놓쳐도 사건의 결과가 남아야 한다.

## 9. 대형 장면 후보

- **도시 일제 점호:** 창문·신호·조명이 구역 순서대로 켜지고 일곱 곳이 비어 있다. 다음 날 여섯 곳만 비어 있어 관계의 변화가 보인다.
- **교정 전선:** 지나간 공간이 더 완벽해질수록 최근의 개조와 NPC의 현재 흔적이 사라진다. 아름다움과 위협을 반전시킨다.
- **외곽 수로 퇴수:** 수백 블록 규모의 수로 아래 대피로·들것·수레·임시 벽·굴착 흔적이 연결되어 드러나고 이후 탐사 경로가 된다.
- **폐전차 시간 객차:** 객차마다 출발 18분 전, 12분 전, 7분 전, 직전의 서로 다른 기록을 통과한다. 현재 만든 물건이 합성된 과거의 모순으로 연결된다.

교정 전선 및 모든 월드 변화는 **사건이 소유하고 사전에 추적한 영역**을 기본 대상으로 삼는다. 플레이어 창작물을 임의 삭제하거나 원본 건축을 빼앗지 않는다. 플레이어와 함께 만드는 후보 장면은 별도 기억 레이어·명시적 참여 영역 등 원본을 보존하는 구현을 먼저 검토한다. 대규모 변경은 예약·진행·완료 검증·저장·재개를 갖춘 뒤 제작한다.

## 10. 회상 연출

Occlusion Transition(차폐 뒤 전환), Audio Pre-lap(소리 선행), Spatial Wipe(공간 경계 전환), Match-on-Action(행동 연결), Source-dependent Reconstruction(자료별 재구성)을 조합한다.

공식 기록·개인 기억·물리적 흔적은 다르게 보일 수 있다. 물리적 흔적이 더 신뢰할 만한 기준이 되고, 그럴듯한 연속기 영상은 오히려 검증 대상이 된다. 암전·순간이동만 반복하지 않는다.

## 11. Free-Look와 놓친 장면

중요 장면이라는 이유로 카메라를 강제로 회전시키지 않는다. 보지 못했어도 사건은 일어나며, 남은 지형·NPC 반응·음향 기록·조사 가능한 흔적으로 다시 이해할 수 있다. 필수 정보는 장면을 정확한 순간에 바라봤는지에 의존하지 않는다.

## 12. Director 경계

| 계층 | 책임 |
|---|---|
| Narrative Beat | 의미·인과·영구 사실은 고정 |
| Ambient Horror Director | 같은 사실을 발견하는 표현과 경로를 다양화 |
| Threat Director | 실제 위험, 신뢰 가능한 전조와 대응법 |
| Recovery Director | 강한 사건 뒤 진짜 휴식 보장 |

**의미는 고정하고 연출 방법을 변화시킨다.** 지도·신호·NPC 전달은 같은 발견으로 연결될 수 있지만 동일 사실을 중복 커밋하지 않는다. 이번에는 기존 telemetry와 훅만 유지한다.

## 13. NoEvent

아무 일도 발생하지 않는 선택도 의도된 레시피로 둔다. 비밀리에 공격을 예약한 가짜 휴식과 실제 휴식을 구분한다. 몬스터 노출을 줄여도 조사와 생활이 남아 있어야 한다.

## 14. 점프스케어의 역할

새 위협 규칙 소개, 핵심 사실 공개, 공간 재해석, 다음 행동 변화 중 하나 이상의 역할이 있을 때 사용한다. 얼굴+비명, 즉시 후방 스폰, 소등→공격, 메모→후방 적, 음악 정지→공격, 문→얼굴을 핵심 공식으로 삼지 않는다.

## 15. 공정성

**서사적 단서는 불확실할 수 있다. 치명적 공격의 전조는 신뢰할 수 있어야 한다.** 무음·자막·저사양에서도 필수 대응 정보가 남아야 한다. 학습한 생존 규칙을 이유 없이 뒤집지 않는다.

## 16. 상태별 시각 언어 — 최종 아트 단계

| 상태 | 언어 |
|---|---|
| 살아 있는 현재 | 비대칭, 개인적인 수리, 서로 다른 조명, 생활 흔적 |
| 연속기의 교정 | 지나친 대칭, 동일 간격·시각, 반복 재료 |
| 공백 | 있어야 할 일부가 빠졌지만 기능은 계속됨 |
| 새로운 현재 | 옛 재료와 새 재료, NPC별 개조, 불규칙함 |

일곱 형체의 정렬은 교정된 상태의 표현으로 재해석한다. 초기 문구 후보는 “일곱 칸. 이름은 모두 긁혀 있었다.”로, 일곱 사람의 정체를 미리 결론 내리지 않는다. 기존 텍스처·도시·문구를 이번에 변경하지 않는다.

## 17. 시작 경험

최종 기본값은 Discovery Mode를 지향한다. 평범한 생존 중 스스로 폐역과 흔적을 발견한다. 진행에 어려움을 겪는 플레이어에게 Guidance를 별도 제공한다. 현재 개발 안내 UI 제거는 발견 가능성·접근성 검증 후 진행한다.

## 18. 프롤로그와 7장

| 장 | 공포 | 진실 또는 질문 |
|---|---|---|
| 프롤로그 — 빈자리 | 정상 생존 속 불일치 | 질문을 남김 |
| 1 — 누가 고쳤지 | 사람 없이 생활권이 수리됨 | 여울과 현재 관계 시작 |
| 2 — 돌아오지 않는 열차 | 철도망에 현재 생활권 등록 | 세계가 현재를 인식 |
| 3 — 어제의 마을 | 지나치게 정상적인 도시 | 마지막 하루의 모순 |
| 4 — 서로 다른 기록 | 자료 간 불일치 | 마지막 하루가 합성본임 |
| 5 — 복원의 대가 | 교정과 현재 경험 삭제 | 사람보다 관계와 빈자리 보존 |
| 6 — 남길 자리 | 과거 실패와 현재 기반 연결 | 새 관계가 현재 인격을 안정시킴 |
| 7 — 마지막 저장 | 규칙을 바꾸는 작전 | 빈자리와 변화의 허용 여부 |

## 19. 히든엔딩 「내일의 자리」

새 원리는 **빈자리도 정상 상태다**. 기록관·기록·과거를 모두 파괴하지 않는다. 기록이 현재를 명령할 권리를 잃는다. 조사·실험·관계·생활 기반으로 이 해법을 이해하고 유지할 수 있어야 하며 마지막 비밀 버튼으로 열지 않는다. 과거의 상실을 전부 취소하지 않는다.

## 20. 조용한 마지막

집마다 불을 켜는 시간이 달라지고 여울의 창문은 꺼져 있어도 여울은 무사히 다른 NPC와 일한다. 도윤은 시간표보다 수리를 택하고 미루는 기록되지 않은 길을 걷는다. “이 도시는 저녁을 넘기지 못했다.”가 저녁→밤→다음 일출로 회수된다. 천문 시간 제한은 아직 구현하지 않으며, 일반 오버월드 생존 시간을 고정하는 요구로 해석하지 않는다.

## 21. Three Lives Rule

각 중요 장소는 원래 일상 → 재난 당시 사용 → 현재의 새 쓰임을 갖는다. 장소마다 정상 기능, 공포, 미스터리, 고유 플레이 행동, 관련 NPC, 엔딩 후 변화에 답한다. 외관 디테일의 양만으로 품질을 판단하지 않는다.

## 22. NPC의 일상

음식 취향·싫어하는 시간·가구 습관·농담·잃어버린 도구·글씨 실수처럼 복선이 아닌 행동도 둔다. NPC↔NPC 관계와 자신의 목표가 플레이어 관계와 독립적으로 존재해야 한다.

## 23. 도구의 서사

기록 탐지기의 세 번째 파형은 초반 미지의 현상 → 연속기와 다른 신호 → 새로운 현재 관계의 신호 → 분산 안정망의 재료로 의미가 확장된다. 탐사·위협 대응·스토리·퍼즐이 연결되되 정답을 표시하는 마법 레이더가 되지 않는다. 최종 해법은 이미 사용해 본 논리를 확장한다.

## 24. 작품의 차별화

공포가 월드 변화로 남음 → 변화가 증거가 됨 → 해답이 NPC 이해로 이어짐 → 이해와 실제 준비가 엔딩을 가능하게 함. 다른 모드와 몬스터·차원·효과 수량을 경쟁하지 않는다.

## 25. 장면 품질 게이트

| ID | 질문 | 필요한 증거 |
|---|---|---|
| No-Spawn | 몬스터 없이도 장면이 성립하는가? | 스폰 제거 플레이 및 공포 평가 |
| No-Stinger | 큰 충격음 없이도 성립하는가? | 충격음 제거 플레이, 접근성 확인 |
| Free-Look | 강제 카메라 없이 가능한가? | 다른 방향/지하/장면 미관측 경로 |
| Causality | 후반 진실로 이유를 설명할 수 있는가? | 사건·증거·세계 규칙 연결 |
| Fairness | 실제 위험에 대응할 수 있었는가? | 공격 전조·대체 정보·대응 검증 |
| Persistence | 사건 뒤 결과가 남는가? | 저장·종료·재접속·재방문 검사 |
| Recontext | 회수 후 초반 의미가 달라지는가? | 최초 해석과 회수 후 해석 비교 |
| Second Run | 반복 플레이에서도 싼 공식이 아닌가? | 재플레이 평가, 패턴 반복 기록 |
| Foreshadow | 반전 전 충분한 단서가 있는가? | 확정적 접근 경로와 선행 증거 |
| Voluntary Revisit | 이해한 뒤 스스로 돌아가고 싶은가? | 강제 퀘스트와 구분한 플레이 관찰 |

주요 psychological setpiece는 No-Spawn + No-Stinger + Free-Look를 동시에 목표로 한다. 선언이나 데이터 필드 존재만으로 PASS 처리하지 않는다. 현재 모든 후보의 위 게이트는 **NOT TESTED**다.

## 안정화 구현과의 연결 경계

1. 현재 lifecycle의 storyId/instance/generation은 엔티티 실행 정체성이다. 미래 Continuity Graph의 역할·관계 정체성과 동일시하거나 기존 필드를 재해석하지 않는다.
2. NPC의 경험 삭제는 서사에서 명시적으로 발생하는 사실이어야 한다. 실제 저장 손상·마이그레이션 누락을 교정 연출로 위장하지 않는다. 플레이어 선택·증거·관계 이력은 감사 가능하게 남긴다.
3. 새로운 관계망·합성 기록·수정 권한·자료 출처 데이터는 별도 설계와 호환성 검증 후 도입한다. 이번에는 schema 또는 기존 월드 진행을 바꾸지 않는다.
4. 연출을 놓치거나 재접속해도 영구 사실·증거·후속 상호작용을 기준으로 진행한다. 순간 소리·카메라·파티클의 프레임 재생은 진행 조건이 아니다.
5. 순서: Wayfarer 예외 검증 → Actor 손상/누락 복구 → 실제 NPC → 복합 사건 → 아이템/보상 트랜잭션 → 구조물 fallback → 통합 무결성 → 자연 생존. 이후 전체 기능·엔딩을 연결하고 마지막에 최종 아트를 한다.
