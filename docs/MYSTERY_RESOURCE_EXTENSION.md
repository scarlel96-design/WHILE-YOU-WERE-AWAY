## 후속 데이터 계약 — 아직 런타임 구현 아님

- **Evidence**: stable ID, 출처·장소·시점, 관찰 사실, 신뢰 맥락, 관련 증거, 재확인 경로, 자막/저효과 대체 표현. 사실과 해석을 별도 필드로 둔다.
- **Investigation**: 발견한 ID, 플레이어 가설/연결, 기각/재검토 상태. UI는 발견하지 않은 핵심 결론을 자동 생성하지 않는다.
- **PuzzleState**: ID, 선행 사실, 확인한 실험, 단계/안전 체크포인트, 멱등 효과, 유일 자원 처리, 대체 해법, 파괴/분실/이탈 복구 정책. 현재 SceneRecord의 연출 확인만으로 퍼즐 보상을 확정하지 않는다.
- **CustomItem**: 기능 ID, 획득/복구 방법, 조작·오류 원인, 세계관 근거, NPC 공동 작업, 자산 키, 소비/변경의 멱등 키.
- **KnowledgeState**: 원리별 증거와 실제 검증 행동. 엔딩을 단순 장비 개수나 숨겨진 점수로 판정하지 않는다.
- **ForeshadowRegistry**: 위 76의 필드와 현재 노출 상태, 회수 구현 상태, 77의 게이트, 의도된 미회수 사유. 주어진 예시가 구현 사실로 섞이지 않도록 planned/implemented/verified를 구분한다.

## 자산 교체 계약

기존 모드 ID는 `whileaway`로 유지한다. 런타임 등록 ID를 미술 교체 때문에 바꾸지 않는다. 자산은 모델·스킨·상태 변형·GUI·음향·파티클의 논리 키로 참조하고 최종 교체 목록을 별도 관리한다. 현재 목록은 `asset-contract.json`이다. 이를 완성형 리소스팩이라고 배포하지 않는다.

최종 팩 비교표에는 공식 출처/버전/허가 문구/수정/재배포/크레딧/변경 이력/성능/셰이더 없는 가독성/충돌 결과를 남긴다. 선택한 자산만 명시적으로 번들하며 게임 전체 기본 텍스처를 일괄 교체할지는 별도 호환성 판단을 거친다.
