## 영구적인 경고

1. **Historical ≠ current.** 예전 AGENTS.md, README, 완료 보고서의 「다음 작업」 지시는 해당 당시의 상태를 나타낼 뿐이다.
2. **Planned ≠ implemented.** 채팅 합의 또는 설계 문서가 존재한다는 이유로 실제 게임 구현/인간 테스트 PASS를 주장하지 않는다.
3. **Scope frozen ≠ roadmap frozen.** V2-03의 진행 중 범위는 보존하되 이후 작업은 최신 사용자의 결정과 새 리서치를 반영한다.
4. **Deep horror ≠ all-lore explained.** Observer와 플레이어 과거는 일률적인 괴물 백스토리로 합치지 않는다.
5. **Beautiful ≠ massive.** 구조물 품질은 덩치보다 구조·재료·동선·생활감으로 판단한다.
6. **Fear first ≠ lore abandoned.** 강한 위험·점프스케어와 장편 퍼즐·감정·엔딩의 모두가 장기 목표다.

## 변경 이력을 추가하는 규칙

새로운 사용자 결정이 나오면 날짜, 정확한 요구 요지, 적용 시점, 대체/유지 관계, 관련 문서 경로를 한 행 추가한다. 앞선 원문을 지워서 변경 이력을 감추지 않는다. 가능하면 반대되는 과거 지침을 명시적으로 superseded로 표시한다. 모델의 개인 제안을 사용자가 확정한 결정으로 기록하지 않는다.
