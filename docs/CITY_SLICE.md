# 0.2 — 저녁골 역전 지구

## 플레이어에게 보이는 것

폐역 신호기가 켜진 뒤에도 문은 바로 열리지 않는다. 귀로꾼과의 첫 만남을 끝내고 개인 기록에서 돌아갈 주소의 흔적을 읽어야 한다. 다시 신호기를 만지면 플레이어는 저녁이 끝나지 않는 도시의 큰길에 선다. 뒤에는 복귀용 불빛을 남긴다.

기록의 인과관계는 하나의 사건을 세 위치에서 드러낸다.

- **접수대:** 의자 스물넷과 이름 서른하나. 지워야 했던 일곱 칸이 남는다.
- **주거동:** 식탁에는 기다리는 사람의 빈자리가 남는다. 낮은 불빛은 복귀 동선과 연결된다.
- **북쪽 방송 기록:** 문을 열면 선로를 덮는 군중, 닫으면 남겨지는 일곱 이름. 방송 담당자는 문을 닫고도 출발음을 끄지 못한다.

세 기록을 읽으면 짧은 연결 문장을 표시한다. 이것은 첫 구역 조사 완료 표시이며 게임의 노말/배드/히든 엔딩이 아니다.

## 코드로 구현한 범위

- `whileaway:quiet_city` 차원·바이옴·고정 밤 설정.
- 80×80 첫 구역, 건물 6동, 도로·등·검문 구조물·기록 블록·복귀 불빛.
- 20,988개의 고유 배치 좌표. 틱마다 최대 256개를 배치하고 건설 커서를 저장한다.
- 완공한 구역은 재진입 요청으로 다시 생성하지 않는다. 플레이어의 블록 변경을 덮어쓰지 않는다.
- 개인별 도시 방문·기록·복귀 좌표/방향·이동 간격 저장. 이전 schema 1은 빈 도시 상태로 이전한다.
- 목적지 충돌/유체/월드 경계를 확인하는 이동, 탑승·사망·수면 중 이동 억제.
- 신호기의 복구 상태를 블록 상태·텍스처·발광에 반영.
- 입장 시 12초 연출과 한글 문장. 차원 로딩 화면이 사라질 때까지 짧게 대기한다.

## 검증 구분

순수 Java 검사는 좌표 중복·범위·기록까지의 평면 보행 경로·출입 조건·기록 중복 처리를 확인한다. Minecraft GameTest는 레지스트리·책·조명·저장 데이터 이전·착지 판정 등을 확인한다.

Minecraft 1.21.1의 GameTestServer는 평지 프리셋에 빈 차원 레지스트리를 결합한다. 따라서 전용 차원 자체의 생성/왕복/재접속 검사는 별도의 실제 통합 서버 클라이언트에서 수행하도록 분리했다. 상세 실행 결과는 `evidence/city/VERIFICATION.txt`에 기록한다.

테스트는 개발용 진행 상태와 관전 모드를 사용한다. 자연 생존 플레이의 첫 발견부터 도시 진입까지를 사람이 끝까지 진행한 기록으로 취급하지 않는다. 두 동시 접속자, 사망 후 복귀, 서버 강제 종료 중 저장 원자성, 다른 셰이더·월드 생성 모드와의 호환은 별도 검사다.

## 다음 단계

지상층별 고유 소품과 동선을 늘리고, 상층 계단·방 구조를 만든다. 도시 괴물은 다음 제작 단계에서 별도의 행동 규칙으로 추가한다. 현재 이 구역은 조사 중심이며 새로운 도시 전용 적은 아직 없다. 건설이 끝난 뒤 레이아웃 순서를 변경하려면 저장 커서와 플레이어 건축물에 대한 이전 전략을 먼저 정한다.
