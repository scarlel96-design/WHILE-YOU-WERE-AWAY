## 완성률 산정 기준
개별 자산이나 테스트 개수를 콘텐츠 완성률로 세지 않는다.
플레이 구간을 생활·탐험·인물·위협·조사·선택의 작업 단위로 분해한다.
각 단위에 예상 플레이 비중과 장소·분기 규모를 기록한다.
계획 전체 단위와 비중이 확정된 후 가중 구현률을 계산한다.
구현률과 사용자 플레이 검증률은 별도로 집계한다.
현재 전체 분모와 플레이 비중이 미확정이므로 전체 완성률은 UNKNOWN이다.
50~60% 구현 후 첫 대규모 사용자 통합 플레이테스트가 목표다.
이번 폐역 한 종으로 그 목표를 달성했다고 판정하지 않는다.

## 폐역 변경
기존 19×10×19 크기와 station anchor (6,1,9), relay (8,1,6)를 유지한다.
기록물 좌표와 기존 보상 상자 NBT도 유지한다.
벽체는 석재 기단·벽돌·목재 보수 부재로 구성한다.
경사지붕과 상부 창은 멀리서 구분되는 실루엣을 만든다.
승강장 보와 달린 조명, 실내 보가 기존 조명을 지지한다.
제작대·보관통·벤치가 실제 사용 공간을 제공한다.
기존에 생성된 역은 재건하지 않는다. 템플릿은 이후 자연 생성에 적용된다.
spacing 20 chunks / separation 8 / salt 74192361을 유지한다.
바이옴: plains, sunflower_plains, forest, birch_forest, taiga, meadow.
새 구조물 생성 빈도는 아직 정하지 않았다.
새 관리소와 통로의 지리적 선로 연결도 아직 구현하지 않았다.

## 사용자 확인 방법
새 월드 또는 아직 생성되지 않은 청크의 폐역을 방문한다.
이전 역과 새 역의 지붕·창·승강장·내부 이동을 비교한다.
다섯 스토리 블록과 상자를 사용한다.
추가 제작대와 보관통을 사용한다.
기존 월드의 역과 플레이어 건축이 바뀌지 않았는지 확인한다.
일반 플레이에서 놓친 구조물은 좌표 지식 없이 찾기 쉬운지도 기록한다.
건축의 미적 품질과 실제 시선 설계는 HUMAN NOT TESTED다.
