# 실제 클라이언트 화면 검토

2026-09-09 최종 runtime.log 실행 결과의 PNG 5개를 직접 열어 확인했다. 생성 이미지나 합성 홍보 화면이 아니다. 기본 렌더러, 셰이더 없음, Intel UHD Graphics 770, 테스트 해상도 854×480의 기록이다.

- city-street.png: 흰 진료소와 붉은 표식, 구리 작업장, 벽돌 건물, 가로등과 폐전차, 길 끝 시계가 확인된다. 도시 진입 자막이 읽힌다.
- city-overview.png: 외곽 수로·둑·고사목·배경 건물, 서로 다른 옥상과 작업장 채광창/굴뚝이 확인된다. 여전히 규칙적인 블록아웃 배치이며 최종 환경 미술은 아니다.
- seven-waiting.png: 의자 아래 창백한 형체 7개가 보인다. 첫 검사에서 몸을 가리던 붉은 블록은 바닥으로 옮겼고, 생존 HUD와 겹치던 자막은 위로 이동했다. 재검사에서 겹침이 해소됐다.
- seven-descending.png: 같은 시점에서 7개 형체가 함께 내려온 상태가 확인된다. 짧은 정지 이후 제거 여부는 실제 클라이언트 검사와 로그로 함께 확인했다.
- city-reloaded.png: 다음 프로세스에서 빈 의자와 바닥 표식은 남고 임시 형체는 남지 않는다. 재접속 안내 채팅은 보인다. 저장된 one-shot 플래그도 검사했다.

프로토타입 한계: 원본 괴물 재질/고급 VFX/최종 인테리어/대도시 전체가 아니다. 청각적 효과는 음소거 검사이므로 청감 평가로 간주하지 않는다. 강한 공포나 감동을 실제 플레이어가 느꼈다는 사용자 경험 시험도 아니다.

최신 사용자 지시에 따라 이번 수정에서 아트 추가를 마감한다. 다음 작업은 FUNCTION_FIRST.md의 기능 게이트다. 특히 이 장면의 중간 종료 후 재개 체크포인트는 아직 없으므로, 해당 복구 기능은 PARTIAL로 남긴다.
