# 기능 우선 개발 기준 — 2026-09-09 사용자 지시 반영

이 문서는 DIRECTION.md와 CITY_SLICE.md의 이전 우선순위를 대체한다. 현재 진행 중인 0.3 개선판을 검증·묶음 배포한 뒤, 최종 아트 추가를 멈추고 기능 안정화와 캠페인 전체 연결을 우선한다. 기본 대상은 Minecraft Java Edition이다.

## 작품의 중심

평범한 생존 생활이 서서히 설명하기 어려운 세계에 연결된다. 오버월드는 단순한 입구가 아니라 지속적인 핵심 무대다. 건축·농사·채광·철도·레드스톤·지도·수면·반복 이동이 이야기와 관계를 진행시킨다. 전용 도시는 서사 밀도가 높은 장소이며 작품 전체를 어드벤처 맵으로 대체하지 않는다.

공포와 감정은 같은 장소·행동·소리·인물의 의미가 바뀌면서 연결된다. 처음에는 무엇이 있는지 두렵고, 중반에는 어떤 일이 있었는지 알게 되며, 후반에는 남은 존재들을 지키기 위해 스스로 돌아온다. 최선의 엔딩은 과거를 지우는 기적이 아니라 남은 사람들이 내일을 선택하는 상태다.

## 완료 판정

코드 존재 → 실제 게임 동작 → 다른 시스템 연결 → 저장·재접속 복구 → 예외 행동 대응 → 관련 시나리오 정상 진행 → 종료 후 정리 → 다음 콘텐츠로 진행. 전부 확인해야 해당 기능을 완료로 표시한다. 빌드 성공·스크린샷·단위 테스트만으로 캠페인 완료를 선언하지 않는다.

증거는 PASS / PARTIAL / NOT TESTED / NOT STARTED로 구분한다. 기능별로 명령, 입력 조건, 결과, 저장 전후 상태, 실패 사례를 남긴다. 연출 효과의 양이나 파일 수는 완료 지표가 아니다.

## 다음 기능 단계의 설계 경계 — 아직 구현 완료 아님

- `CampaignState`: 개인 진행과 월드 공유 상태를 구분한다. chapter, facts, decisions, facilities, ending, epilogue를 버전 있는 저장 레코드로 관리한다.
- `EventJournal`: instanceId, eventId, participantIds, prerequisiteSnapshot, status, checkpoint, committedEffects, ownedChanges, startedAt, completedAt, interruptionReason을 저장한다. 준비→실행→체크포인트→확정→정리를 구분하고 효과별 멱등 키를 둔다. 클라이언트 화면 종료는 이야기 보상 확정과 분리한다.
- `FearState`: WorldAwareness, AnomalyPressure, PlayerExposure, ThreatActivity, SafetyState, RecentFearPattern, RegionInstability를 서사 장과 별개로 관리한다. 안전한 휴식에서는 실제 새 위협 발생을 막는다.
- `FearDirector`: Delayed Recognition, Spatial Contradiction, Peripheral Presence, False Safety, Environmental Possession, Social Mimicry, Observation Horror, Rule-Based Horror, Auditory Horror, Memory Horror의 최근 이력을 제한된 길이로 저장한다. 학습한 규칙·패턴·방향·종·음향의 반복을 피한다. 현재 구현한 단순 Director가 이 설계를 모두 충족한다고 취급하지 않는다.
- `NpcRegistry`: 서사 인물의 안정적인 ID와 실제 엔티티 UUID, 마지막 차원/청크, 생존 상태, 목표, 관계를 별도 관리한다. 엔티티가 현재 로드되지 않았다는 이유만으로 새로 생성하지 않는다. 복사된 월드는 자체 저장 상태에서 계속되며 외부 전역 저장소와 진행을 공유하지 않는다.
- `PresentationPorts`: CameraCue, SoundCue(priority/category), NpcAction, StructureTransition, LightCue, ParticleCue, WeatherCue를 이벤트 훅으로 받는다. 서버가 상태 전이를 소유하며 클라이언트는 제한된 연출만 수행한다. 저효과 모드의 대체 자막/사물 단서를 함께 정의한다.
- `OwnedWorldChanges`: 사전 블록 상태와 기대 현재 상태가 맞을 때만 변경·복구한다. 플레이어가 수정한 블록을 복구 작업이 다시 덮어쓰지 않도록 한다.
- `EndingResolver`: 누적 사실과 복수 생활 기반 조합으로 결과를 계산하고 근거를 진단 로그에 남긴다. 최종 대화는 이미 쌓인 세계 상태를 확인하는 과정이며 단일 점수 판정으로 대체하지 않는다.
