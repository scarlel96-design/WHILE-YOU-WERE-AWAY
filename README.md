# 《네가 없는 동안》 — 사건 체크포인트 0.3.1-dev.1

**Minecraft Java 1.21.1 · NeoForge 21.1.249 · GeckoLib 4.9.2 · Java 21**

오버월드에서 자연 생성되는 폐역을 발견하고, 남겨진 기록을 읽고, 신호를 복구하면서 이상 현상과 첫 괴물 **귀로꾼**을 만나는 개발용 모드입니다. 폐역 이후에는 전용 도시 차원의 첫 80×80 구역으로 진입합니다. 전체 도시와 다중 엔딩 캠페인은 후속 개발입니다.

## 설치

1. 별도 테스트용 Minecraft Java **1.21.1** 프로필에 **NeoForge 21.1.249**를 설치합니다.
2. 해당 프로필의 `mods` 폴더에 `dist/whileaway-0.3.1-dev.1.jar`와 **GeckoLib NeoForge 1.21.1용 4.9.2**를 넣습니다. Fabric/Forge용 파일과 구분합니다.
3. 구조물 생성을 켠 새 월드를 만듭니다. 자연 진행은 보통 난이도 생존 모드가 기준입니다.
4. 평원·숲·자작나무 숲·타이가·초원에서 폐역을 찾습니다. 기존 월드라면 새로 생성되는 청크가 필요합니다.

다운로드 출처: [NeoForge](https://neoforged.net/), [GeckoLib 공식 프로젝트](https://github.com/bernie-g/geckolib). 이 배포물에는 Minecraft 본체나 GeckoLib JAR를 동봉하지 않습니다.

## 현재 플레이 가능한 흐름

- 폐역 접근 → 역의 존재를 발견합니다.
- 기록 블록 우클릭 → 책을 받습니다. **책을 직접 열어 읽어야** 단서가 기록됩니다.
- 경고 기록을 읽고 레드스톤 1개로 신호기를 복구합니다. 역 안 상자에 재료가 있습니다.
- 서로 다른 단서가 쌓이면 먼 노크 → 돌아오는 발소리 → 귀로꾼 출현으로 진행합니다.
- 귀로꾼은 즉시 덮치지 않습니다. 첫 유예 구간을 거친 뒤 가까이 접근하면 공격 전조를 보입니다. 역에서 충분히 멀어지거나 물리치면 첫 만남이 끝납니다.
- 귀로꾼 관찰용 생성 알은 주인을 지정하지 않은 비공격 개체를 만듭니다. 자연 조우와 다릅니다.

기본 간격은 90초이며, 재접속 30초·독서 60초 유예가 있습니다. 같은 책을 반복해서 열어도 단서 수가 늘지 않습니다. 정지 상태·독서 유예·평화로움·크리에이티브/관전·낮은 체력·주변 적의 공격 상황에는 새 조우를 억제합니다. 이 규칙은 이미 시작된 전투의 무적 기능과는 다릅니다.

## 이번 연출 구현

신호 복구 시 **12초짜리 공간 연출**을 실행합니다. 위치가 다른 노크와 발소리, 희미한 재 입자, 가장자리의 약한 어두움, 짧은 두 문장을 순서대로 배치합니다. 화면 전체를 번쩍이거나 카메라를 강제로 돌리는 방식은 사용하지 않습니다. 메뉴/책을 열거나 현장을 떠나거나 차원을 이동하면 연출 타임라인을 중단합니다.

괴물에는 접힌 신체 모델과 대기·보행·추격 애니메이션이 있습니다. 현재 텍스처는 게임에 설치된 기본 엔더맨 텍스처를 참조하는 임시 재질입니다. 최종 괴물 아트가 아닙니다.

효과음 5개와 음악 큐 2개는 새로 합성한 원본 프로토타입입니다. 기본 Minecraft 음원을 변조하거나 동봉하지 않았습니다. 최종 공간 믹싱과 작곡은 후속 작업입니다.

## 무음 개발 규칙

**개발자가 실행하는 모든 클라이언트는 시작 전 전체 소리·모든 소리 분류·내레이터를 0으로 설정합니다.** `runClient`, `runClientSmoke`, `runCitySmoke`, `runCityReload` 모두 적용합니다. 기존 개인 게임 프로필과 운영체제 볼륨은 변경하지 않습니다. 소리 파일은 재생 대신 디코딩·길이·샘플 피크·호출 시점을 검사합니다. 실제 청감 평가는 별도로 남아 있습니다.

일반 설치용 JAR 자체는 플레이어의 음량 설정을 덮어쓰지 않습니다. 자동 검증용 클라이언트와 사용자가 직접 플레이하는 프로필을 분리합니다.

## 개발/검증

Java 21에서 프로젝트 루트를 기준으로 실행합니다.

```powershell
.\gradlew.bat build runGameTestServer --console=plain
.\gradlew.bat runClientSmoke --console=plain
python .\tools\verify-assets.py .\build\libs\whileaway-0.3.1-dev.1.jar
```

`runClientSmoke`는 별도 월드를 자동 생성하고 무음 상태에서 자연 구조물, 클라이언트 리소스, 연출 패킷, 스크린샷을 검사한 뒤 종료합니다. **Gradle 성공만으로 클라이언트 검증 통과로 판정하지 않습니다.** 로그의 `WHILEAWAY_SMOKE_PASS`, 증거 파일, 스크린샷을 함께 확인합니다.

개발용 명령:

```text
/locate structure whileaway:abandoned_station
/whileaway status
/whileaway recover
```

`recover`는 운영자용이며 현재 로드된 조우 개체를 정리하는 기능입니다. 로드되지 않은 개체의 중복 생성을 막기 위해 해당 상황에서는 초기화를 보류합니다. 일반적인 장 전체 초기화 명령은 아닙니다.

## 완료 범위와 남은 작업

**구현:** 폐역 1종, 기록 3종, 신호 복구, 단서/조우 저장, 귀로꾼 1종, 단계형 디렉터, 12초 연출, 한·영 텍스트, 원본 오디오 7개, 자동 테스트.

**미구현:** 도시 전체와 나머지 구역, 나머지 괴물, 장기 퀘스트/인물 관계, 선택의 누적 결과, 배드·노말·히든 해피 엔딩, 최종 모델/텍스처/사운드, 셰이더 호환 최적화. 멀티플레이 실제 두 클라이언트와 생존 전체 진행 수동 플레이테스트도 별도입니다.

## 0.2: 저녁골 역전 지구

1. 폐역에서 신호를 복구하고 귀로꾼과의 첫 만남을 마칩니다.
2. **개인 기록**을 읽은 뒤 폐역 신호기를 다시 우클릭합니다. 다른 플레이어가 켠 신호기라도 개인별 진행 조건을 확인합니다.
3. 도시 준비 중이라는 문장이 나오면 잠시 후 다시 우클릭합니다. 건설은 신호 복구 시부터 작은 묶음으로 진행하며, 준비가 끝나기 전에는 플레이어를 이동시키지 않습니다.
4. 도시에서는 접수대 장부·식탁 아래 편지·방송실 교대표를 찾아 책을 엽니다. 읽은 기록은 개인별로 저장합니다.
5. 도착 지점 뒤의 **돌아가는 불빛**을 우클릭하거나 `/whileaway return`을 입력하면 원래 오버월드 위치 근처로 복귀합니다. 목적지가 막혀 있으면 블록을 부수지 않고 빈 자리를 찾습니다.

현재 도시에는 건물 6동, 중앙 도로와 교차로, 가로등, 접수대·주거동·북쪽 검문 구조물, 3종의 2페이지 기록이 있습니다. 건물의 지상층을 탐색할 수 있고 상층은 외관용 껍데기입니다. 80×80 크기의 한 구역이며 무한 생성 도시가 아닙니다.

도시 진입은 침대/리스폰 위치를 덮어쓰지 않습니다. 현재 차원 설정에서 침대와 리스폰 앵커를 사용하면 바닐라의 차원 부적합 폭발 동작이 적용됩니다. 복귀는 돌아가는 불빛이나 복귀 명령을 사용합니다. 세계 저장 데이터는 schema 1에서 2로 이어받습니다. 0.2로 진행한 월드에 0.1을 다시 적용하는 것은 호환 검증 대상이 아닙니다. 되돌리기 스크립트는 **JAR 복사본만** 복구합니다.

개발용 도시 검증:

```powershell
.\gradlew.bat build runGameTestServer runCitySmoke runCityReload --console=plain
```

첫 클라이언트는 별도 월드에서 접근 조건·도시 생성·책 사용·왕복·재방문을 검사하고 종료합니다. 두 번째 클라이언트는 같은 저장을 다시 열어 차원 위치·도시 기록·복귀 지점·블록 변경 보존을 검사합니다. 실제 소리는 재생하지 않습니다.

## 0.3 추가 사항

건물별 재질·발코니·옥상·파손 부위, 폐전차와 시계탑, 외곽 수로·고사목·배경 건물을 추가했습니다. 접수 장부와 연결되는 **일곱 형체의 동시 낙하 장면**도 구현했습니다. 자세한 조건과 남은 아트 작업은 [ART_PASS.md](docs/ART_PASS.md)를 확인하세요.

**이미 생성한 0.2 도시는 덮어쓰지 않습니다. 새 미술 배치는 새 테스트 월드에서 확인하세요.** 0.3 빌드와 실제 무음 클라이언트 증거는 `evidence/art`에, 배포 JAR와 소스 묶음은 dist에 있습니다. 위 0.2 설명은 이전 도시 진입부의 기록입니다.


## 이후 개발 우선순위

최종 건축·환경·NPC 외형·고급 연출은 기능 안정화 이후로 미룹니다. 오버월드 생존 생활을 핵심 무대로 유지하며, 두려웠던 장소와 존재를 지키고 싶어지는 장편 경험을 목표로 합니다. [기능 우선 기준](docs/FUNCTION_FIRST.md)에 사용자 요청 32항목, 18단계 순서, 완료 게이트, 다음 기능 결손을 기록했습니다. 다음 최우선은 **중단된 사건의 체크포인트 복구 → 필수 구조물 대체 경로 → 사망·청크·차원·월드 복사 예외 회귀**입니다.
